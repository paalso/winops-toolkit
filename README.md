# winops-toolkit

PowerShell scripts for Windows configuration, hardening and administration automation.

Набор PowerShell-утилит для автоматизации настройки, конфигурирования и администрирования Windows.

> ⚠️ Скрипты вносят системные изменения (реестр, политики, устройства). Перед использованием на рабочих машинах обязательно проверяйте их на тестовой среде и делайте резервные копии.

## Возможности

- Автоматизация типовых задач настройки Windows
- Применение политик безопасности и hardening
- Интерактивные меню и понятный вывод
- Скрипты автономны: достаточно PowerShell, без внешних зависимостей

## Безопасность

- Запускайте скрипты только от имени администратора и только из доверенного источника.
- Ограничьте права на папки со скриптами и списками для обычных пользователей.
- Изучите код перед запуском, особенно если он изменяет политики.
- Рекомендуется иметь план отката (экспорт веток реестра, точка восстановления).
